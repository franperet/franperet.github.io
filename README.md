# franperet.github.io

Portfolio de Francisco Peret, hecho con HTML, CSS y JavaScript, sin frameworks.

- **Ver en local:** abrir `index.html` con doble clic.
- **Cambiar el contenido:** todo el texto, los proyectos y los links están en `js/data.js`.
- **Imágenes y CV:** van en `assets/` (por ejemplo `assets/img/` y `assets/cv.pdf`) y se referencian desde `js/data.js`.
